# Daily Tech Radar & X Post Drafts (2026-11-20)

## 1. 本日の注目技術トレンド

- **Discord「Project Phoenix」公式プレビュー：脱Electron・Rust共通コア＋GPUI＋WebAssembly（海外テックニュース / GitHub・Zenn周辺話題）**
  - Discord共同創業者兼CTOのStanislav Vishnevskiy氏がプレビュー公開。デスクトップ版のElectronおよびモバイル版のReact Nativeを廃止し、アプリの中核ロジックを単一の**Rustコア**へ統合する計画。
  - デスクトップUIにはZedエディタチーム発のGPUアクセラレーション対応Rust製フレームワーク **GPUI** を採用し、ブラウザ版ではアプリケーションロジックを **WebAssembly（WASM）** にコンパイルして共有。
  - Windows 11上の初期プレビューでは複数アカウント稼働時でもメモリ消費量が **約290MB**（従来のElectron版はアイドル時1〜2GB、高負荷時4GB超）に収まり、起動時間もミリ秒単位へ短縮されたことが話題。
- **「Self-Improvement Memory Enables Continual Recursive Self-Improvement」（Google Cloud AI・DeepMind・Penn State / arXiv:2611.18856 / Hugging Face Daily Papers）**
  - LLMの重みではなくエージェントの外部実行枠組み（ハーネス）を再帰的に自己改善させる際、ベースモデルやベンチマークが切り替わると過去の最適化文脈が失われる課題（CRSI）を定式化。
  - ハーネス最適化器向けの構造化記憶台帳 **Self-Improvement Memory（SIM）** を提案し、修正理由・予測と実測の差分・評価コンテキストを記録することで、コーディング連続タスクにおいてコードのみ引き継ぐ従来手法を平均 **+2.36ポイント**（$p=0.003$）上回った。
- **「MMFlash: Faster Speculative Decoding for Vision-Language Models」（arXiv:2611.18482 / Hugging Face Daily Papers）**
  - マルチモーダルVLMの投機的デコーディングにおけるボトルネックを、トークン単位の「視覚依存度（KLダイバージェンス）」で計測。視覚依存トークンに重み付けした学習と長尺動画向けスパースAttentionにより、無損失で最大 **3.58倍** の高速化を達成。
- **`rtk-ai/rtk` (Rust Token Killer)（GitHub Trending Rust / AI開発ツール）**
  - Claude Code等のAIコーディングエージェントが `git status` や `cargo test` 等のCLI出力でコンテキストを浪費する課題に対し、Rust製の単一バイナリCLIプロキシとして出力を傍受・圧縮し、推論精度を落とさずLLMトークン消費を **60〜90%削減** するツールとして注目を集めている。

## 2. 既存プロジェクトとのシナジー分析

- **Markdown TeX Viewer（Typst WASM × ブラウザPWA / Android）**:
  - Rust製の次世代組版エンジン `Typst` をWebAssembly化してWeb Worker上で動かし、入力中の60fps DOMプレビュー（KaTeX / Markdown-it）とサーバーレスのベクターPDF出力を両立している構成が、Discord「Project Phoenix」の「UIは標準HTML/DOM、計算・状態コアはRust→WASM」という設計と構造的に一致。
- **Symple Audio Splitter & DarkModePDF & ZeroConvert-IME**:
  - Symple Audio Splitter（ブラウザ完結のフレームコピーで30分m4aを21秒→約0.23秒書き出し）、ZeroConvert-IME（Windows/Android共有変換コア＋18.7 MiB Nano v4.1で推論メモリ約35MB・CPUコールド中央値20.96ms）など、脱重量ランタイム・脱Electronの個人開発における具体的な計測知見と、Zennで話題の「速く・軽くした代わりにどこが重くなるか（WASM境界コスト・UIプラットフォーム分岐・マルチターゲットビルド）」のトレードオフが直結する。

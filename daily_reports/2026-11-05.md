# Daily Tech Radar & X Post Drafts (2026-11-05)

## 1. 本日の注目技術トレンド
- **SLM（Small Language Model）の急速な台頭**
  - 0.5B〜14Bクラスの小型モデルが知識蒸留と高精度量子化によって実用域に到達。
  - クラウドAPIの従量課金や通信遅延を嫌うエッジ・オンデバイス用途での導入が加速。
- **WebAssembly (WASM) / WebGPU によるインブラウザAI**
  - WebLLMやTransformers.jsにより、環境構築不要でブラウザ完結のクライアントサイド推論が一般化。
- **オンデバイスAIとレイテンシ**
  - NPUの標準化に伴い、「速さ」と「完全プライベート（通信不要）」がUI/UX（特にIMEやエディタ）で決定的な差に。

## 2. 既存プロジェクトとのシナジー分析
- **ZeroConvert-IME (0.09B / 18.7MiB)**:
  - 世間のSLMブーム（0.5B〜）よりもさらに2桁小さい極小モデルでストリーミング推論を実現している点は、非常に際立った差別化要素。
  - 「エッジAI」「オンデバイス推論」の文脈で発信することで、AIエンジニアや組み込み・ネイティブ開発層からの関心を獲得可能。
- **Typst WASM / Markdown TeX Viewer**:
  - インブラウザWASM技術の実践例として、ブラウザ完結処理のトレンドと親和性が高い。

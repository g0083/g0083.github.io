# Daily Tech Radar & X Post Drafts (2026-11-19)

## 1. 本日の注目技術トレンド

- **「Weight-Space Programming Doesn't Need Transformers」（POSTECH / arXiv:2611.22055 / Hugging Face Daily Papers / Zenn話題）**
  - Hyunjong Ok氏・Jaeho Lee氏（POSTECH）による最新論文。勾配降下法（Backpropagation）を使わずLLMが推論モデルの重みを直接書き換える（Weight-Space Programming）なら、勾配学習と密行列積に最適化されたTransformerを使う必然性はないと指摘。
  - 3つのフロンティアLLMにゼロからアーキテクチャと重みを設計させたところ、すべてTransformerを拒否し、**「1ファクト1行のスパース連想メモリテーブル」＋「固定クエリ手順」**を自ら選択。
  - LLMが手書きした最良のTransformerと比較して、**約1,800分の1のパラメータ数で上回るテスト精度**と**最大17倍のGPU推論速度**を達成し、誤答時は該当行を直接パッチできる高いデバッグ性を示した。
- **Google「Gemini 4 Neon」GAリリース & OpenAI「GPT-6.2 Astra / Sol」発表（2026-11-17〜18）**
  - Googleは2026年11月18日に「Gemini 4 Neon」（GA）を公開。最上位Carbonと軽量Hydrogenの中間に位置する主力モデルで、100万トークン対応・思考深度4段階（`low` / `medium` / `high` / `xhigh`）の動的調整が可能。
  - OpenAIは2026年11月17〜18日にフラッグシップ推論モデル「GPT-6.2 Astra」と日常ワークフロー向け「GPT-6.2 Sol」を発表。カスタム推論チップ（Jalapeño）設計へのAI活用も公開。
- **NGINX HTTP/2 重大脆弱性公表（CVE-2026-123007 / CVE-2026-123633 / はてなブックマークITホットエントリー / 2026-11-18）**

  - JPCERT/IPAが注意喚起を行い、`nginx 1.30.7`（Stable）および `nginx 1.31.9`（Mainline）で修正済み。

## 2. 既存プロジェクトとのシナジー分析

- **ZeroConvert-IME (0.09B Standard v4 / 18.7 MiB Nano v4.1)**:
  - 11月4日の記事（`weight-space-programming-zerocon.html`）で検証したとおり、90.5MのTransformer重みを直接編集して全角・半角数字キメラ（`１0キロ走る`）は直せた一方、`100円`→`1000円`のような高頻度アトラクターや語彙欠落には重み編集が破綻することを実測していた。
  - 11月15日のv0.7.0（`zerocon-nano-v4-1-model-accuracy.html`）では数値処理をTransformerから切り離し、Swift/Rust/C++/Kotlin共有の `nam` マスク＋2パス復元へ逃がすことで数値復元率100.0%・740問総合97.16%を達成した。
  - 本日のPOSTECH論文（`arXiv:2611.22055`）は、「勾配なしで直接書き込む記憶・規則にTransformerは不向きで、スパース連想テーブルの方が約1,800分の1のサイズ・17倍高速」と理論実証しており、ZeroConvert-IMEのハイブリッド責務分離設計と完全に構造が一致している。

Typo Correction / Release v0.9.0

タイポ補正の高速化と追従再調整――編集中レイテンシ35.0ms→14.5ms、誤補正は自動で元へ

2026.11.27 著者: g0083 (O-ya tech) 対象バージョン: ZeroConvert-IME v0.9.0

タイポ補正は正確であるほど重くなりやすく、しかも文の途中で一度直した箇所が、後ろの文字を打ち足したときに噛み合わなくなることがあります。ZeroConvert-IME v0.9.0ではAIによる補正判定の応答時間を大幅に削りつつ、後続の文脈に合わせて自動補正を再調整・自動取り消しする仕組みを加えました。本稿は性能の結果と使い心地をまとめます。

補正レイテンシと450問ベンチマークの結果

Windows（Intel Core i5-14500HX・CPU実行・Nano v4.2 IQ4_emb8）で、入力や削除を繰り返す編集中シーケンス422回と、タイポ255問＋正常入力195問の計450問セットを測定した結果です。

測定項目 最適化前 最適化後 (v0.9.0)
編集中シーケンス 平均遅延（422回） 35.04 ms 14.47 ms（約59%短縮）
編集中シーケンス 中央値 / p95 31.94 / 51.75 ms 19.59 / 32.91 ms
220ms超過（遅延スパイク） 1回 0回
450問 合計壁時間 35.25秒 25.06秒（約29%短縮）
タイポ正解（255問中・完全一致） 197問 200問
正常入力の保持（195問中） 190問 192問

Android実機（450問）でも、Snapdragon 8 Eliteで全体4.36秒（1問あたり約9.7 ms）、Dimensity 8020で22.36秒（1問あたり約49.7 ms）で完了しています。AIモデルが文脈を見ながら誤字を直しているにもかかわらず、編集のたびに待たされる感覚がありません。

使い心地の変化：追従再調整・自動取り消し・12キーフリック

  • 文脈に合わせた再調整と自動取り消し：入力が長くなってから「実は先ほどの語は正しい入力だった」「別の直し方のほうが自然だ」と分かった場合、自動で元の入力へ戻したり、より自然な補正へ切り替えたりします。2箇所目のタイポもそのまま保護されます。
  • Escキーでの原入力復元：補正がかかった状態でもEscキーを押せば、打ち間違えを含む生の入力へワンタッチで戻せます。
  • 数字混在・12キーフリック対応：数字を含む文の読み処理を整え、Androidの12キーフリック入力モードにも対応を広げました。

まとめ

v0.9.0のタイポ補正は編集中の平均遅延を14.47 msまで縮め、速さと安全性の両方を引き上げました。固定ベンチマークの詳細は GitHub Releases をご覧ください。

ZeroConvert-IME v0.9.0 cuts typo-correction latency during live editing (422 edit/delete steps) from 35.04 ms to 14.47 ms on Windows CPU while improving 450-case total wall time from 35.25 s to 25.06 s, typo exact matches from 197/255 to 200/255, and clean preservation from 190/195 to 192/195. Automatic context refinement, auto-revert, Esc raw-input restore, and Android 12-key flick support are included. Performance summary only.

私が開発している日本語IME「ZeroConvert-IME」は、変換キーを押す操作そのものを減らすことを目指しています。その中心にある極小モデル「ZeroCon Model Nano」は、わずか 18.7 MiB / 6層・約26.7Mパラメータ で、開発評価（480問）で 総合正解率92.7%、タイポ補正 78.0% という性能を実現しました。

本記事は、学習の内部手法ではなく性能の結果だけをまとめます。サイズ・精度・速度がどう変わったかをご覧ください。

1. ベースモデルからの性能向上

開発評価ベンチマーク（基本・文脈230問＋高難度250問＝全480問）における単体性能の比較です。

わずか 18.7 MB のサイズで、ベースモデルから 92問（+19.2ポイント）改善しました。180MB超の12層モデルとほぼ同等の精度を、6層の軽量モデルで実現しています。

2. タイポ補正の性能

タイポ補正は、従来の構成では正解率 20.8% でした。メイン変換モデルで一貫して処理する構成へ移行した結果、78.0%（実質86.7%） へ向上し、常駐メモリも削減できました。変換精度を保ちながら、打ち間違いの救済を両立できることが性能の大きな変化です。

3. サイズと速度

軽量な量子化により、推論時の追加コストなしで 18.7 MiB に収まり、CPU推論は平均 23ms 程度です。PC・スマートフォンの常駐用途でも、打鍵に追従できる速度を維持しています。

4. 評価の考え方

性能の主張は、学習データと評価データを分離し、日常会話や数字・記号などの退行がないことも合わせて確認した結果に基づきます。固定データセット上の測定値であり、未知の実入力すべてを保証するものではありません。

5. おわりに

小さなモデルでも、用途を絞って性能を高めることで、変換キーを押さずに文字を紡ぐ体験に近づけられます。Windows版インストーラーおよびAndroid版APKを GitHub Releases で公開しています。

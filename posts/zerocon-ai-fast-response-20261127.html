AIが動いているのに1打鍵5〜7ms――ZeroConvert-IME v0.9.0の応答速度と処理時間削減

2026.11.27 著者: g0083 (O-ya tech) 対象バージョン: ZeroConvert-IME v0.9.0

AI搭載の日本語IMEと聞くと、変換のたびにワンテンポ待たされる印象を持つ人は少なくありません。ZeroConvert-IME v0.9.0では推論エンジン全体のオーバーヘッドを見直し、ローカルAIが毎打鍵動いているにもかかわらず、人間の打鍵リズムに余裕で追いつく応答速度に到達しました。本稿では実装の内部ではなく、実測した性能の結果だけをまとめます。

ポイント：60Hzの1フレーム（16.6ms）より速いAI変換

Windows CPU環境（Nano v4.2 IQ4_emb8・18.7 MiB）のライブ変換プロファイルでは、1打鍵あたりの平均処理時間が 5.31〜6.60 ms になりました。840問の一括ベンチマークでも、旧エンジンの 24.55秒 → 7.69秒（CPU） / 6.58秒（Vulkan） まで縮んでいます。

Windows：840問共通候補生成のBefore / After

同じPC（Intel Core i5-14500HX・CPU実行およびNVIDIA GeForce RTX 4070・Vulkan実行）と同一の840問評価セットで、旧エンジンとv0.9.0世代の新エンジンを比較した結果が下の表です。Zenzaiの生成と辞書候補の統合・順位付けまでを含んでいます。

Nano v4.2 IQ4_emb8はCPU単体でも壁時間が約3.2分の1、1問あたりの平均応答が26.65 msから7.21 msへ落ちました。GPUを使える環境なら99 MiB級のStandard v4.2 Q8でさえ平均11.96 msで回り、99.6%の正答率と即応性を同時に確保できます。

打鍵ごとのライブ変換：平均5.31〜6.60ms

一括ベンチマークだけでなく、1文字打つごとにライブ変換を走らせる打鍵プロファイル（Nano v4.2 IQ4_emb8・Windows CPU・各条件2,040回計測）も測りました。

文脈条件（2,040回ずつ計測） 平均 中央値 (p50) p95
空文脈ライブ変換 5.31 ms 5.31 ms 8.98 ms
長文脈ライブ変換 6.60 ms 5.85 ms 13.85 ms
数式・記号文脈ライブ変換 6.44 ms 5.97 ms 12.57 ms

95%の打鍵が9〜14ms以内で完了するため、画面が次のフレームを描画するより先にAIの変換候補が届きます。入力中にAIが裏で動いていることを意識させないレスポンスです。

Android実機と実行時自動チューニング

スマートフォンでも同じ傾向が出ています。実行環境に合わせてCPUスレッド数や変換モードを初回起動時などに自動調整する仕組みを入れたことで、実機上の変換負荷が大きく下がりました。

Android実機（Nano v4.2 IQ4_emb8） 計測内容 最適化前 最適化後
Snapdragon 8 Elite (OPD2415) 200問エンジン実測平均 71.95 ms 32.92 ms（約2.2倍高速）
Snapdragon 8 Elite (OPD2415) 840問 共通候補生成 20.92秒 11.80秒
Dimensity 8020 200問エンジン実測平均 172.65 ms 119.70 ms（約31%短縮）
Dimensity 8020 840問 共通候補生成 52.23秒 47.27秒

Snapdragon 8 Eliteでは200問の実エンジン計測が平均32.92 msまで縮み、モバイルCPUだけでも軽快なライブ変換が成立しています。ミドル帯のDimensity 8020でも約31%の短縮を確認しました。

使い心地の変化

速記のように続けて文字を打っても、未確定の文字列が後からガタついて追いかけてくる感覚が消えました。従来の辞書ベースIMEと同じリズムのまま、文脈判断や口語表現、自動確定といったローカルAIの恩恵を受けられます。また、WindowsとAndroidのどちらでも端末のCPU構成に応じた自動チューニングが働くため、ユーザーが手動でスレッド数を探り当てる手間もありません。

まとめ

ZeroConvert-IME v0.9.0では、18.7 MiBのNano v4.2 IQ4_emb8がWindows CPUで1打鍵平均5〜7ms台、840問全体で7.69秒（Vulkanなら6.58秒）、AndroidのSnapdragon 8 Eliteで平均32.92 msまで高速化しました。AIが動いているから遅いという妥協を外したリリースです。配布ファイルと詳細な検証記録は GitHub Releases をご覧ください。

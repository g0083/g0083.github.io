全国住所・町字辞書（161万組超）とオンデマンド軽量配布――辞書2.5倍でも変換遅延ほぼゼロ増

2026.11.27 著者: g0083 (O-ya tech) 対象バージョン: ZeroConvert-IME v0.9.0 / dictionary-v2

地名や町名・大字は読みが難しく、入力中に変換候補が出ないと住所入力そのものが止まります。一方で、辞書を大きくすると検索が重くなったり、インストーラーやAPKが肥大化したりする問題も起きます。ZeroConvert-IME v0.9.0では全国住所・町字を取り込んだdictionary-v2へ拡張しつつ、モデルと辞書を初回起動時のオンデマンド取得へ切り替えて配布サイズを半分以下に削りました。本稿は性能とサイズの結果だけをまとめます。

161万8,968組への拡張と変換遅延の比較

デジタル庁の全国市区町村マスターおよび全国町字マスター（727,535行）と日本郵便データを取り込み、989,465組を新たに加えました。収録数の増加に対して、Windows上の変換・辞書引き遅延がどう変わったかを測った結果です。

比較項目 拡張前 (dictionary-v1) 拡張後 (dictionary-v2)
逆引き・収録組数 629,045組 1,618,968組（約2.57倍）
辞書検索単体 p50（全語彙） 2.52 ms 2.54 ms（+0.02 ms）
辞書検索単体 p50（地名ケース） 2.51 ms 2.55 ms（+0.04 ms）
CPU変換全体 p50 5.41 ms 5.51 ms（+0.10 ms）

辞書の組数が2.57倍に増えたにもかかわらず、普段の辞書引きp50は0.02〜0.04 msしか変わっていません。Androidでも逆引き索引をファイルのままメモリマップする構成へ改めたことで、省メモリのまま高速に引けます。

オンデマンド取得で配布ファイル容量を半減以下へ

v0.9.0では、変換モデル・日本語辞書・英字辞書をWindowsインストーラーとAndroid APKの本体から切り離しました。初回起動時に1つの確認画面で3点をまとめて案内し、SHA-256検証付きでダウンロードする方式です。これにより配布ファイル自体が大幅に軽くなりました。

配布ファイル v0.8.0 v0.9.0
Windows インストーラー (.exe) 142.46 MiB 61.99 MiB（約56%削減）
Android ARM64 APK 122.32 MiB 50.36 MiB（約59%削減）
Android Universal APK 155.40 MiB 83.78 MiB（約46%削減）

使い心地の改善：英語編集・表示統一・ライセンス一覧

  • 未確定読みとカーソル表示の統一：WindowsとAndroidで変換中の未確定読み表示と移動カーソルの見た目を揃えました。
  • 英語モードの単語内編集：英字入力中に単語の途中へカーソルを戻して編集できるようになりました。
  • 利用規約・ライセンス全文ビューア：WindowsとAndroidで共通のライセンス一覧と全文表示画面を備えています。

まとめ

ZeroConvert-IME v0.9.0では全国の町字・丁目まで一発で出せる161万組超の辞書を備えつつ、配布ファイルは半分以下の50〜62 MiB台へ軽量化しました。最新のインストーラーとAPKは GitHub Releases から取得できます。

ZeroConvert-IME v0.9.0 introduces dictionary-v2 (1,618,968 pairs including nationwide municipalities and town/chome addresses, 2.57x larger than v1) while keeping median dictionary lookup latency virtually unchanged (2.52 ms to 2.54 ms). Moving models and dictionaries to verified on-demand first-launch downloads also shrinks the Windows installer from 142.46 MiB to 61.99 MiB and the Android ARM64 APK from 122.32 MiB to 50.36 MiB. Performance summary only.

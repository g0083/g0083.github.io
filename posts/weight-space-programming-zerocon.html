【検証】話題の「Weight-Space Programming」を0.09Bの極小言語モデルで試してみた 〜勾配計算なしでモデルのバグは直せるのか？〜

Related Project / 関連プロジェクト ZeroConvert-IME
変換操作をゼロに近づける次世代AI日本語IME（Windows / Android）
トップで見る ↗ GitHub

重みを直接分析して不具合の原因を調べ、追加の再学習なしに修正できるかを、極小の日本語変換モデル（ZeroCon Model Standard v4）で試しました。本記事は手法の内部ではなく、性能の結果だけをまとめます。

対象と結果

変換ベンチマーク（480問）で 95.62%（459/480問） という精度でしたが、数字の表記が混ざる誤変換が残っていました。出力の分析から原因を特定し、修正した結果、対象ケースは正しく出力されるようになりました。他の数字変換への悪影響は確認されませんでした。

分かったこと

局所的な表記の問題は、重みの分析で原因を絞り込むことができました。一方、語彙の不足や頻度の高い表記への偏りなど、広く分布した問題は重みの調整だけでは直しにくいことも分かりました。そのため、そうした問題はデータやパイプライン側の改善で対応しています。

まとめ

極小モデルでも、出力分析によって局所的な誤変換を再学習なしに修正できる場合があります。性能面では、修正後もベンチマーク全体の精度を維持できたことが確認できました。

Analyzing outputs of a 0.09B model to fix a localized conversion error without retraining, while preserving overall accuracy.
